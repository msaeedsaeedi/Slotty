\section{Known gaps}
\begin{risk}
  \textbf{No web application firewall.} AWS WAF costs about \$10 a month, which the bootstrap
  budget does not cover; API Gateway throttling is the only rate limit (ADR-009).
\end{risk}
\begin{risk}
  \textbf{Usage data is pseudonymous, not anonymous.} Someone with both database access and
  \envvar{ANALYTICS_SECRET} could recompute every user's visitor key. Feedback text is free text
  and can contain whatever a person types; the form asks them not to include personal details.
  With small courses, role plus page type plus time can narrow down who sent a message, which is
  why feedback times are rounded to the hour and survey answers to the day.
\end{risk}
\begin{risk}
  \textbf{The content security policy only reports.} It does not block injected scripts yet
  (\cref{sec:usage-analytics}).
\end{risk}
\begin{risk}
  \textbf{Management-account access uses an IAM user with long-lived keys.} Moving operators to
  IAM Identity Center with MFA would remove them.
\end{risk}
\begin{risk}
  \textbf{SMTP uses long-lived IAM user credentials} (ADR-008), limited to sending from the
  domain. Rotate them on a schedule.
\end{risk}
