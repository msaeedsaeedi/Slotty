\section{Context}
Slotty is one web application used by four roles. It sends email and push notifications and
offers calendar entries; everything else happens inside it. \Cref{fig:context} shows what it
talks to.

\section{Quality goals}
In priority order. Each one is a reason behind a decision in \cref{ch:decisions}.
\begin{enumerate}
  \item \textbf{Rules hold under concurrency.} No slot over capacity, no double booking, no
    lost change budget, even when many students book the same minute (\cref{ch:rules}).
  \item \textbf{Marks stay private until released.} Students see only finalized results, never
    private notes; every moderation-relevant change is audited.
  \item \textbf{Available on demo days.} Demo days are the peak and the moment failure hurts
    most: the web tier runs in two availability zones and scales out on load.
  \item \textbf{Cheap at bootstrap.} Under \$50 a month on AWS, with growth by changing
    variables rather than re-architecting (\cref{ch:cost}).
  \item \textbf{Auditable and changeable.} Infrastructure is code, changes go through AI-DLC
    with approval gates and an audit trail (\cref{ch:aidlc}), and this document is kept current.
\end{enumerate}

\section{Constraints}
\begin{itemize}
  \item One AWS region (us-east-1) in a dedicated account, enforced by service control policies (\cref{sec:aws-guardrails}).
  \item Monthly budget of \$50 for the account.
  \item Course times are shown in the course timezone; only Pakistan time is offered for now.
  \item Stack: Next.js 16 (App Router), React 19, Prisma 7 with PostgreSQL 17, Bun for tooling
    and the worker build; Node 22 in production.
\end{itemize}
