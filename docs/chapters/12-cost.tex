\begin{note}
  Usage analytics adds no AWS service (ADR-015). About 300 users send roughly 50\,000 events a
  month, batched into a few thousand extra API Gateway requests (a few cents) and well under
  100 MB of database storage at 90 days' retention. It stays inside the API Gateway and RDS lines
  above.
\end{note}

\begin{note}
  The live notification bell (issue \#9) checks \route{/api/notifications/unread} every 30
  seconds while a tab is visible. At 300 students with about an hour a day in the app that is
  roughly 540\,000 requests a month, about \$0.55 on API Gateway, plus one indexed count query
  each on RDS. It stays inside the lines above.
\end{note}

\section{Growth}
Each step is a variable change in \src{infra/aws/app/variables.tf} (some also need an SCP
change in \src{infra/aws/org/scp.tf}):

\begin{xltabular}{\linewidth}{@{}L r@{}}
  \toprule
  \thead{Change} & \thead{About \$ / month}\\
  \midrule

  \tfvar{web_max = 6}, \tfvar{db_instance_class = "db.t4g.small"} & 60\\
  \quad + \tfvar{db_multi_az = true} and an Application Load Balancer & 90\\
  \quad + \tfvar{nat_mode = "gateway"} and AWS WAF & 135\\
